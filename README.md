# PythonProject — premiers exercices Python

Dépôt d'apprentissage : scripts élémentaires, pas une application de production.
Ces exercices montrent les **fondamentaux en cours d'acquisition**, et non mon niveau professionnel actuel.

## Exercice exécutable

```bash
python3 main.py
python3 -m unittest discover -s tests -v
```

`main.py` calcule le total d'un panier, avec une fonction testable et de petits contrôles d'entrée.
Les autres fichiers à la racine sont des exercices historiques, conservés pour suivre la progression.
